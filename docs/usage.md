# 使用指南

## 设置页

插件设置页为标题、说明和控件保留边距。按钮及下拉控件的宽度适配文字，窄面板中会换行排列，便于完整显示和操作；这些布局调整只作用于 WeRead Pocket 设置。

## 本地书架与阅读来源

执行命令「打开本地书架」，或打开「设置 → WeRead Pocket → 阅读偏好 → 本地书架」。使用「添加 EPUB/TXT」选择电脑上的一个或多个文件；「从仓库添加」列出当前仓库中的支持文件，由你选择加入。也可执行「添加本地图书（EPUB / TXT）」命令。

插件在左侧文件列表创建 `WeRead Pocket/`，导入图书统一复制到这里，外部原文件保持原样。已经位于该文件夹中的文件可直接加入书架；点击该文件夹中的 EPUB、TXT 会使用 WeRead Pocket 阅读。书架中的移除仅移除记录与插件保存的进度，不删除图书文件。旧版外部文件引用迁入此文件夹时保留阅读进度。

- **EPUB：** 使用书内目录和阅读顺序生成章节列表，默认原书 / 原文排版，保留受支持的书内文本样式；可改为自定义排版，使用现有字号、行距、段距与留白。
- **TXT：** 识别 UTF-8、UTF-16 或常见 GB18030 中文编码，并根据章节标题切分；没有明显标题时使用分段章节。默认保留原文行首空格与换行，可改为自定义排版。
- **继续阅读：** 每本书分别保存当前章节与章内阅读位置，下次打开时恢复。书架可按书名或作者查找，并按最近阅读、书名、添加时间排序。
- **切换来源：** 先保存当前阅读位置，再释放上一来源的阅读界面。进入本地来源会关闭官方网页；返回微信读书重新加载最近阅读地址，登录资料由原持久会话保留。离开本地来源会释放章节 DOM、图片 URL 与图书文件句柄，下次打开恢复逐书进度。本地图书使用同样的工具栏、窗口位置、主题、排版和文献卡片；这些偏好按位置与显示模式保存。

点击目录按钮可跳到所选章节。设置中的「跨章节连续阅读」默认开启：滚动到章节边界时自动衔接相邻章节，不显示上一章 / 下一章按钮。阅读器按需保留当前章与相邻章节，最多三章；远离的章节会释放，避免全书同时展开。

关闭「跨章节连续阅读」后，每次显示一个章节，使用前后章节按钮或目录切换。此开关控制本地来源的连续滚动；选择分页阅读时仍按页操作。文献卡片使用连续滚动，也遵循此跨章开关。

图书保存在仓库的 `WeRead Pocket/` 中；导入后移动外部原文件不会影响阅读。在该文件夹内重命名单个图书会保留书架记录与进度；将图书移出受管理文件夹或删除图书会移除对应记录，之后可重新导入。当前版本支持可重排、未加密的 EPUB 和 TXT；PDF、MOBI、AZW3、固定版式 EPUB、ZIP64 或加密 EPUB 暂不支持。阅读器只接管 `WeRead Pocket/` 内 EPUB、TXT 的打开，其他位置的文件仍按 Obsidian 原有方式打开，不会扫描整个电脑或下载图书。

## 本地书签与全文搜索

本地阅读时，小窗工具栏点击书签图标；完整侧栏或标签页打开「更多」菜单。可选择「添加当前位置书签」「本书书签」「搜索本书正文」。命令面板中也有对应的「本地图书」命令，可以在 Obsidian 快捷键设置中自行绑定。

书签记录章节、段落和段内位置，并显示该段短摘录。每本书单独保存，最多 500 个；重复添加近乎相同的位置会提示已有书签。点击书签返回该位置，点击「移除」仅移除书签。重命名或迁移书架文件保留书签，移出书架会移除该书记录及书签。

全文搜索扫描当前 EPUB/TXT 的全部正文，不区分英文字母大小写，输入视为普通文字。搜索显示章节进度和匹配摘录，最多显示 200 条；命中很多时可输入更完整的词句。点击结果会跳到匹配位置并短暂高亮。停止按钮可结束当前扫描，关闭面板、换书或切换来源会自动取消。未读取成功的章节会提示，结果不代表这些章节已搜索完成。

搜索逐章读取，不保存常驻的全文索引。搜索结果和查询词不写入书籍或插件设置，书签通过插件数据保存。本地搜索不搜索微信读书网页，也不把正文上传到网络。

## 阅读位置

| 位置 | 适合的场景 | 操作 |
| --- | --- | --- |
| 浮动小窗 | 临时阅读，拖动工具栏移动 | 顶栏切换；调整小窗大小 |
| 侧栏底部小窗 | 上半部保留其他插件，下半部阅读 | 开启「小窗固定到右侧栏底部」 |
| 完整右侧栏 | 固定在右侧的阅读页 | 顶栏「移至侧栏」 |
| 工作区标签页 | 较宽的完整阅读区域 | 顶栏「移回标签页」 |

同一来源下切换窗口位置复用当前阅读表面，不因移动到小窗、侧栏或标签页而重新加载。切换本地 / 微信读书来源会释放上一来源，重新进入时需要加载；以本地来源启动时不会先创建官方网页。微信读书自身的书籍或章节导航仍可能发起网络加载。

## 字号与间距

顶栏的 A− / A+ 调整当前阅读位置的字号；本地原书 / 原文排版下保留书内样式，切换自定义排版后可调整字号与间距。排版按钮展开以下选项：

- **正文字号：** 改变正文和文献卡片摘录的文字大小。
- **行间距：** 同一段中每行文字的高度。
- **段间距：** 两个正文段落之间的额外空白。设为 0 后，字体自身的行高与原文换行仍然存在。
- **左右留白：** 同时改变两侧间距，最小值 4 px。极窄区域会限制留白，以保留可读的正文宽度。

普通阅读与文献卡片分别保存排版；每种模式中的浮动小窗、底部小窗、完整侧栏、标签页也各自记忆。插件设置中的「各窗口排版」与顶栏共用同一组数据；每项可恢复默认。

设置或顶栏排版面板中的「本地正文排版」提供两种方式，默认选择原书 / 原文排版：

- **原书 / 原文排版：** EPUB 保留受支持的本地 CSS、类名与行内文本样式，包括字号、缩进、行距、段距、文字对齐与段落结构；TXT 没有 CSS，保留原文行首空格与换行。背景与文字颜色仍跟随当前主题。书内样式经筛选并限定在阅读器范围内，仅解析书内 CSS 和本地 @import，不加载外部 CSS、字体与脚本或为它们发起网络请求；定位样式不进入正文，复杂版式不保证完整还原。
- **自定义排版：** EPUB、TXT 使用 WeRead Pocket 的字号、字体、行距、段距与左右留白。普通正文首行缩进两个字，归一化原文已有的段首缩进空白，避免重复缩进；标题、列表、表格与代码保持各自布局。

文献卡片继续使用本插件自己的字体和间距，不套用原书样式。

高级选项中的「小窗网页缩放」缩放整个网页，包括目录与界面。只需改变正文大小时优先使用正文字号。文献卡片小窗保持 100% 网页缩放，以保持与侧栏卡片一致的文字大小；该模式直接使用独立的字号与间距设置。

## 阅读控制快捷键

在「设置 → WeRead Pocket → 阅读控制快捷键」设置以下四个操作。每项显示当前绑定；「更改快捷键」打开 Obsidian 标准快捷键页，可更换或清除绑定，「恢复默认」恢复下表中的按键。修改即时应用于本地和微信读书来源。macOS 的 Mod 对应 Cmd，Alt 对应 Option。

| 操作 | Windows 默认键 | 行为 |
| --- | --- | --- |
| 向上滚动 | `Ctrl+Alt+↑` | 连续滚动向上约三行；分页阅读转到上一页 |
| 向下滚动 | `Ctrl+Alt+↓` | 连续滚动向下约三行；分页阅读转到下一页 |
| 上一章 | `Ctrl+Alt+PageUp` | 跳到上一章开头 |
| 下一章 | `Ctrl+Alt+PageDown` | 跳到下一章开头 |

按住滚动键可连续滚动；按一下章节键切换一章，在第一章和最后一章按图书边界停止。支持浮动小窗、侧栏底部小窗、右侧栏、标签页以及文献卡片。焦点在 Obsidian 笔记编辑器或其他主界面控件时也生效，阅读操作保持原焦点，可以继续编辑。

这些是 Obsidian 内的命令快捷键；其他应用获得焦点时不会控制阅读。未加载图书时不执行阅读操作，也不会为快捷键额外创建网页或重新打开来源。与其他命令冲突时，可在标准快捷键页查看冲突并更换绑定。

## 收起与展开

默认快捷键 Ctrl+Alt+R：按一次收起，第二次恢复到原阅读位置。可在「设置 → 快捷键」搜索 WeRead Pocket 修改。此快捷键是当前项目保留的默认值；与其他快捷键冲突时请更换。

小窗工具栏可固定在上、下、左、右。浮动与底部小窗各自记忆位置，不随鼠标接近自动跳边。

自动收起可选择：

- 鼠标移出后收起，等待 450 毫秒；及时移回可取消。
- 鼠标移出后点击外部收起。

底部小窗还能选择移入工具栏展开，或点击工具栏展开。点击展开时，第一次点击只展开正文，不执行该按钮的功能。

## 文献卡片

打开「设置 → WeRead Pocket → 文献卡片外观」，分别选择 **浮动小窗、侧栏底部小窗、右侧栏阅读、工作区标签页** 是否使用卡片。每个位置有独立开关，默认关闭，可单独恢复默认。例如只开启侧栏底部小窗时，移回标签页会使用普通阅读，回到底部小窗会自动恢复卡片。

顶栏菜单与命令只切换当前位置的卡片开关。修改其他位置的开关不会移动阅读器，也不会切换当前窗口的分页阅读；进入启用卡片的位置时使用连续滚动。切换位置会自动应用对应的普通或卡片字号、间距和标题，复用当前来源的阅读界面。

文献标题、英文摘录和每张卡片包含的段落数由所有启用卡片的位置共用。英文摘录之间用空行分隔；卡片按顺序循环使用。

从旧版升级时，原全局开关的值会复制到四个位置，以保留原有显示行为；之后可以逐一调整。

它使用连续滚动，隐藏小说章节标题，并更换阅读顶栏标题。默认使用 12 px 字号、1.3 倍行距、4 px 段距与 12 px 左右留白，贴近侧栏文献卡片的紧凑外观。卡片内部保留 8 px 内缩，避免正文贴住边框。英文摘录使用左对齐；英文与中文片段使用同一字体、字号和行高，避免网页片段样式把中文字体改回官方默认。工具栏修改的是当前位置的卡片排版。关闭后恢复普通阅读及该位置原先的普通排版。自定义英文仅作为纯文本显示，不解析 HTML。此模式不生成文献、引用、Zotero 批注或学术笔记。

卡片底部在正文后收拢。“重点”和“阅读笔记”标签及整行已移除，原标签区域的预留高度和分隔线也一并删除。

卡片图标与英文左侧色条使用同一种颜色。每章采用稳定的五色伪随机顺序；同章滚动重绘、调整窗口或切换阅读位置时不会重新随机变色。

| 颜色 | 色值 |
| --- | --- |
| 黄色 | `#ffd400` |
| 红色 | `#ff6666` |
| 绿色 | `#5fb236` |
| 蓝色 | `#2ea8e5` |
| 淡紫色 | `#a28ae5` |

侧栏底部的文献卡片会检测上方同一侧栏中的受支持文献卡片。在默认留白下，阅读卡片的左右外边界和彩色引线对齐该参考卡片；调整留白时，在参考边界的基础上变宽或变窄。没有参考卡片时使用自身的对称留白。

## 热门划线与笔记

此功能仅适用于微信读书官方网页，本地图书没有他人的热门划线与公开想法。切换至本地来源时不请求这些笔记，也不把本地正文转换成官方划线；返回微信读书后仍使用原先保存的显示偏好。

打开「设置 → WeRead Pocket → 热门划线与笔记」，先选择 **普通阅读** 或 **文献卡片**，再为 **浮动小窗、侧栏底部小窗、右侧栏阅读、工作区标签页** 分别设置显示。两种外观各有四项，共八个独立偏好；新安装均默认开启，每一项都可恢复默认。

顶栏菜单只切换当前外观和当前位置的划线显示。设置其他外观或位置的开关时，当前页面保持原样；进入对应位置或切换外观后，自动应用那一项偏好。例如可以显示普通标签页的划线，同时隐藏底部文献卡片的划线。

从旧版升级时，原全局显示值会复制到八项，以保留原有的开启或隐藏状态。分页时由官方阅读器控制划线显示，但仍可提前设置这些偏好；回到连续滚动后应用对应开关。

划线位置对应原生正文。按住鼠标拖动仍用于选中文字，直接点击热门虚线可查看相关公开想法；没有公开想法或加载失败时显示提示。窄窗中的笔记面板可滚动，用 × 关闭面板。

## 外观与官方工具

阅读外观可跟随主界面、使用深色或使用浅色。跟随主界面读取当前主题的背景、文字及边框颜色。

插件顶栏保留来源切换、本地书架、目录、排版和窗口控制。以下官方网页工具设置仅作用于微信读书来源。可另外隐藏网页底部的书城 / App 提示，调整官方圆形工具的左右位置或隐藏它们。小窗目录字号单独控制目录与搜索框，正文不受影响。

## 图书文件与笔记

`WeRead Pocket/` 专门保存导入的本地图书。逐书进度保存在插件数据中，插件不再生成微信读书概要、目录或进度 Markdown 笔记。

从旧版升级不会自动删除已有的微信读书概要笔记；确认不需要后，可自行将原文件夹移入系统废纸篓。网页阅读与扫码登录继续使用微信读书官方服务。
