# 兼容性与实现限制

## 声明范围

当前版本的 `minAppVersion` 为 **1.13.7**，`isDesktopOnly` 为 `true`。实际验证环境为 Windows 桌面版；macOS、Linux 与其他 Obsidian 版本尚未完成实际验证。手机端不支持 Electron webview，不能使用此插件。

项目的文件结构与元数据按 Obsidian 插件规范准备，**这不等于通过社区目录审核**。发布前需要执行发布清单并处理审查反馈。

## 本地图书范围

| 格式 | 当前处理范围 |
| --- | --- |
| EPUB | 未加密的可重排 EPUB；按书内阅读顺序与目录读取章节，支持原书文本样式或自定义排版 |
| TXT | UTF-8、UTF-16、GB18030 常见文本；自动识别章节标题并生成目录 |
| PDF / MOBI / AZW3 | 当前本地书架不支持；PDF 可继续用 Obsidian 的核心查看器打开 |
| DRM / 固定版式 / ZIP64 EPUB | 不支持解密、ZIP64 容器或保证固定版式还原 |

「本地正文排版」默认原书 / 原文排版。EPUB 保留经过筛选的本地 CSS、类名与行内文本样式，支持字号、缩进、行距、段距、文字对齐与段落结构，作用范围限定在当前阅读器；TXT 没有出版方 CSS，保留原文行首空格与换行。背景与文字颜色仍跟随主题，脚本、外部 CSS、字体、定位样式及交互组件不进入正文，URL 与 @import 不会联网获取；复杂版式不保证完整还原。

可在设置或排版面板选择自定义排版，使用 WeRead Pocket 的字号、字体、行距、段距与留白；普通正文首行缩进两个字，并归一化已有段首缩进空白。标题、列表、表格、代码不强加正文缩进，文献卡片继续使用本插件的外观。

当前章节内的受支持位图可从 EPUB 自身资源读取；外部资源不会自动联网获取。复杂表格、脚注与多媒体的完整还原不属于本次文本来源接入的保证范围。TXT 编码与自动章节识别依赖原文件结构；无法识别标题时以分段章节提供导航。

导入图书统一保存于仓库的 `WeRead Pocket/`；仓库外原文件保留，不被改写。旧版外部书架引用迁入此文件夹时保留逐书进度。仓库内的图书可通过现有文件同步服务同步；书架索引与进度仍通过插件数据接口保存，能否跨设备携带取决于该服务是否同步插件数据。只有此文件夹内的 EPUB、TXT 使用本插件的文件打开入口，其他文件保持原有打开方式。

只解析正在打开的书，不为每本书创建浏览器实例。跨章节连续阅读在连续滚动时最多保留三个相邻章节的显示 DOM，按需加载与释放；关闭时只显示当前章。此方式限制常驻章数，但单个特别大的章节仍可能占用较多内存。分页阅读保持按页操作。本地来源本身不发起网络请求，也不保留官方网页；以本地来源启动时不会创建官方网页。来源切换会释放上一来源的阅读界面、章节资源与文件句柄；只有同一来源的窗口位置切换复用现有界面。返回微信读书需要重新加载最近阅读地址，原持久会话中的登录资料仍保留。本地阅读不需要微信账号。

## 资源控制与搜索限制

相邻章节预加载受节点数量限制，当前章节超过约 12000 个节点时停止预加载，预加载后的总节点超过约 20000 时跳过相邻章。用户主动打开的单个章节仍完整渲染，超大章节会较慢。图片仅在接近可见区域时读取，保留已有压缩大小限制，并在解码前检查像素尺寸：单张最多 1200 万像素，当前已载入图片合计最多 2400 万像素。不支持或超限图片显示替代文字，这些限制不等同于整个 Obsidian 的内存上限。

本地搜索按章节读取纯文字，支持文字跨行内标签匹配；不支持正则表达式、OCR 或微信读书的全书搜索。最多 200 条结果，每本书最多 500 个书签。搜索取消可立即停止后续章节读取；正在进行的文件读取会在返回后丢弃结果。大型章节解析期间仍可能短暂占用主线程。

微信读书分页的小窗会按当前字号和行距保留最小阅读高度，避免页面标题挤掉正文。窗口本身过小时仍受屏幕可用空间限制。

## 未公开接口

下面这些实现不属于稳定的 Obsidian 或微信读书公共 API：

| 依赖 | 用途 | 可能的影响 |
| --- | --- | --- |
| Electron webview、持久 session、`@electron/remote` | 官方网页、登录会话、键盘输入与窗口状态 | 宿主 Electron 升级可能影响网页嵌入 |
| guest debugger / Chrome DevTools Protocol | 找到微信读书原生阅读器并绑定桥接 | 宿主限制调试访问时，布局与划线功能可能失效 |
| 微信读书原生组件、store 与渲染字段 | 调整字体和布局、保留画布偏移、恢复热门划线 | 官方网页内部重构可能需要适配 |
| 官方签名对象与同源笔记接口 | 读取点击位置的公开想法并打开原生笔记面板 | 登录、权限、签名或返回格式变化可能阻止加载 |

桥接脚本只在嵌入的官方阅读页中运行。它读取原生渲染元数据并绘制显示层，不从本地下载整本小说。私有接口不保证兼容；请求失败时显示提示，不能据此承诺所有书籍或章节始终可用。

## 可选的侧栏卡片对齐

文献卡片模式下，底部小窗可读取同一侧栏上方的 `.zt-annot-card` 元素边界，作为默认左右留白和彩色引线的对齐参考。这是对特定文献侧栏界面的显示适配，不是通用 Zotero API，也不读取、写入或同步该卡片的文献和批注内容。

参考卡片不存在或无法测量时，使用阅读器自身的对称留白。其他文献插件、类名变更、主题布局变化可能使自动对齐失去参考，需要重新适配。

## 账号与数据边界

网页登录由微信和微信读书处理，购买、会员和访问权限由服务提供方决定。浏览器会话保存于 Obsidian 应用数据区，不随本项目打包。书架索引、逐书进度与插件偏好通过 `loadData / saveData` 持久化，公开项目和发布附件应排除这些个人数据。

微信读书概要笔记同步已移除，插件不会自动清理其他用户已有的 Markdown 笔记，也不会把本地图书进度回传至微信读书。EPUB、TXT 是独立的离线来源，不从官方服务下载全书。热门划线笔记请求在官方网页会话中发出，不经本项目的中转服务器。

## 社区提交前关注项

保留默认 Ctrl+Alt+R，以及阅读控制的 Ctrl+Alt+↑ / ↓、Ctrl+Alt+PageUp / PageDown，是本地项目的明确使用需求；Obsidian 开发建议通常避免默认命令快捷键。各项均可更改、清除或恢复默认；公开提交前需要考虑改为用户手动绑定，并验证冲突处理。

阅读网页中的 CSS 与原生画布布局有动态生成部分。它们限定在插件阅读页范围，仍需对照最新审查工具检查无障碍、样式与资源清理。私有接口与动态桥接可能需要人工解释，自动检查通过也不代表审核通过。
