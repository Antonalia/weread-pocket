# 功能演示图片

这些 PNG 用于项目 README，展示阅读窗口、本地书架、书签、全文搜索、文献卡片、排版、连续阅读、小窗行为、快捷键及热门划线笔记。

- 图书《河岸来信》《城市散步》《夜航札记》、正文、工作笔记和示例读者均为自编演示内容，未使用个人书库、账号资料或真实读者记录。
- 阅读器、卡片、书架、书签、搜索和设置预览使用本项目组件与排版源码生成；预览环境提供桌面主题基础样式。工作区和公开想法使用演示内容说明布局。
- `reading-windows.png` 对照展示不同阅读位置；实际使用时，在位置之间复用同一个阅读器。
- 图中的配色与字体仅为演示，实际外观随 Obsidian 主题和用户设置变化。
